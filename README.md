# منصة إدارة مخيمات النازحين — النموذج الأولي للواجهة

نموذج أولي كامل لواجهة المستخدم (Frontend Prototype) لمنصة تسجيل وإدارة النازحين في المخيمات.

**HTML5 + CSS3 + JavaScript (ES6 Modules) فقط.** لا يوجد باك-إند، ولا قاعدة بيانات، ولا مصادقة حقيقية.

---

## التشغيل

المشروع يستخدم ES Modules، لذلك يجب تشغيله عبر خادم محلي (فتح الملف مباشرة بـ `file://` لن يعمل).

```bash
# أي من الطرق التالية
npx serve .
python -m http.server 3000
# أو إضافة Live Server في VS Code
```

ثم افتح `http://localhost:3000`.

### فصل الطبقات

الترتيب مقصود لتسهيل التحويل لاحقاً إلى Next.js 16 + Supabase:

- **`data/mock-data.js`** — بيانات خام فقط، بلا أي DOM.
- **`core/store.js`** — الوحيد الذي يلمس `localStorage`. واجهة كل مجموعة (`list` / `get` / `create` / `update` / `remove`) مصمّمة على شكل استدعاءات Supabase، فيُستبدل محتوى الملف لاحقاً دون تغيير ما فوقه.
- **`core/selectors.js`** — منطق المجال (البحث، الإحصاءات، نطاق الصلاحيات).
- **`core/auth.js`** — الجلسة وجدول الصلاحيات `can()`.
- **`ui/*`** — مكوّنات عرض لا تعرف شيئاً عن معنى البيانات.
- **`js/pages/*`** — ربط فقط: قراءة الرابط ← نداء المخزن ← نداء واجهة العرض.

`ui/layout.js` هو المكافئ لـ `layout.tsx`، وكل ملف في `js/pages/` هو المكافئ لمكوّن مسار.

## البيانات التجريبية

تُحفظ في `localStorage` عند أول تشغيل، وتشمل: 3 مخيمات · 5 مؤسسات · 8 أسر · 24 نازحاً · 14 مساعدة · 5 طلبات تسجيل · 12 مستنداً · 6 رسائل · 8 إشعارات.

البيانات مترابطة: كل نازح ينتمي إلى أسرة موجودة، ورب كل أسرة أحد أفرادها وفي المخيم نفسه، وكل مساعدة تشير إلى مؤسسة وأسرة موجودتين. يمكن التحقق من ذلك في وحدة تحكم المتصفح عبر `store.validateData()`.

لإعادة ضبط البيانات: **الإعدادات ← إعادة ضبط البيانات التجريبية**، أو مسح `localStorage` من أدوات المطوّر.

## قواعد المجال المطبّقة في الواجهة

1. مدير نظام واحد فقط، ومسؤولو مخيمات متعددون.
2. مسؤول المخيم هو مندوب المخيم — لا يوجد حقل منفصل لاسم المندوب.
3. منع التسجيل المكرر يعتمد على **رقم الهوية** فقط، ولا يمكن التسجيل في أكثر من مخيم بنفس الرقم.
4. لا يوجد رقم خيمة ولا رقم كرفان — يُستخدم **نوع الخيمة** بدلاً منها.
5. الحقول الصحية هي **الأمراض المزمنة** و**الإعاقة** فقط.
6. القسم الاقتصادي لا يحتوي على "احتياجات الأسرة".
7. المستندات بلا تواريخ انتهاء.
8. البحث لا يشمل رقم الملف ولا رقم الخيمة.
9. المساعدات يضيفها ويعدّلها ويحذفها **مسؤول المخيم فقط**؛ النازح يطّلع عليها فقط.
10. المؤسسة تحتوي على **اسم المؤسسة** و**الشخص المسؤول (اختياري)** فقط.
11. الأسرة كيان مستقل له رقم فريد يُولَّد تلقائياً بصيغة `FAM-000001`.
